# ☕ Coffee Sales Dashboard

## Overview
This project presents an interactive Coffee Sales Dashboard built using Tableau. It analyzes sales performance, customer trends, product categories, and revenue to help businesses make data-driven decisions.

## Features
- Interactive Tableau dashboard
- Sales trend analysis
- Product category performance
- Customer insights
- Revenue and profit visualization
- Region-wise sales analysis

## Tech Stack
- Tableau
- Data Visualization

## Files
```
Coffee-Sales-Dashboard.twb
Coffee-Sales-Dashboard.pages
README.md
```

## Dashboard Insights
- Top-selling coffee products
- Monthly sales trends
- Revenue distribution
- Customer purchasing patterns
- Regional performance comparison

## How to View
1. Download the repository.
2. Open the `.twb` file using Tableau Desktop.
3. Explore the interactive dashboard.
